# Contributing to SuprKandi

The repository is public, but protected branches should not allow unrestricted direct changes.

## Contribution Flow

1. Fork the repository.
2. Create a feature branch.
3. Make focused changes.
4. Add or update tests.
5. Run `npm test`.
6. Run `npm pack --dry-run`.
7. Open a pull request.

Changes to translation, execution, evidence, security, or reporting should include tests.

Do not commit passwords, tokens, API keys, database credentials, or `.env` files containing secrets.

By contributing, you agree that your contribution may be distributed under the Apache-2.0 license.
